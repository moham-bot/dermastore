# ريمشي — المتجر الطبي التجميلي (Remshy Dermocosmetics)

منصة تجارة إلكترونية متخصصة في مستحضرات التجميل العلاجية وطب الجلدية (Dermocosmetics)، مبنية بأحدث تقنيات **Django 5** و **Tailwind CSS** و **HTMX** و **Alpine.js** مع لوحة إدارة طبية مخصصة مدعومة بـ **Django Unfold** وتكامل سحابي كامل مع **Cloudinary**.

---

## ✨ المميزات الرئيسية

### 1. الكتالوج والتسوق السريري
- كتالوج منتجات متكامل مع فلاتر تفاعلية فائقة السرعة بواسطة **HTMX** (نوع البشرة، المشكلة الجلدية، خطوات الروتين، فلاتر الأمان).
- محرك أسعار متعدد العملات بالوقت الفعلي (**YER**، **SAR**، **USD**).
- حاسبة تسوق تفاعلية مع شريط هدايا تحفيزي وشحن مجاني.

### 2. أدوات صيدلانية تفاعلية متقدمة
- **خريطة الوجه التفاعلية (Interactive Face Mapper):** رسم بياني تفاعلي لتحديد مشاكل مناطق الوجه وتوصيات العلاج المخصصة.
- **المستشار الصيدلاني الذكي (5-Step Diagnostic Quiz):** تشخيص نوع البشرة ومشاكلها وبناء وصفة طبية قابلة للطباعة وتنزيل بطاقة روتين مخصصة.
- **مختبر التوافق الكيميائي (Compatibility Lab):** فحص فوري للتعارضات بين المواد الفعالة (مثل فيتامين C مع الريتينول أو النياسيناميد) وتنبيه المستخدم.
- **مجدول التدوير الجلدي (Skin Cycling Generator):** جدول أسبوعي ذكي لروتين الـ 4 ليالٍ (تقشير، ريتينول، تعافي، تعافي).
- **مفكك المكونات (INCI Decoder):** تحليل المكونات الكيميائية وتصنيفها وظيفياً وأمانها على البشرة.
- **جدول المقارنة السريري (Side-by-side Comparator):** مقارنة تفصيلية جنباً إلى جنب حتى 3 منتجات.

### 3. تكامل Cloudinary السحابي للصور
- رفع صور المنتجات تلقائياً من الهاتف أو الكمبيوتر مباشرة من لوحة الإدارة.
- معاينة حية فورية للصورة قبل الرفع.
- تحسين الصور التلقائي باستخدام `f_auto` و `q_auto` عبر Cloudinary CDN.
- استبدال تلقائي وحذف للصور السابقة من السحابة عند التعديل أو الحذف.
- محرك احتياطي ثلاثي للصور ينتهي برسمة SVG طبية سريرية ديناميكية للمنتج.

### 4. الطلب وفاتورة الواتساب الذكية
- إنشاء فاتورة رقمية احترافية وإرسال الطلب مع جدول الروتين اليومي مباشرة إلى رقم واتساب المتجر بنقرة واحدة.

## 🛠️ التثبيت والتشغيل المحلي

### 1. استنساخ المشروع وتثبيت الاعتماديات:
```bash
git clone https://github.com/moham-bot/dermastore.git
cd dermastore
python -m venv venv
# تفعيل البيئة الافتراضية
# على ويندوز:
venv\Scripts\activate
# على لينكس/ماك:
source venv/bin/activate

pip install -r requirements.txt
```

### 2. إعداد المتغيرات البيئية:
انسخ ملف `.env.example` إلى `.env` واملأ بياناتك:
```bash
cp .env.example .env
```
محتوى `.env`:
```env
DEBUG=True
SECRET_KEY=your-django-secret-key
ALLOWED_HOSTS=localhost,127.0.0.1

# Cloudinary
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret

# WhatsApp Business
WHATSAPP_NUMBER=967778550938
```

### 3. تجهيز قاعدة البيانات وتشغيل السيرفر:
```bash
python manage.py migrate
python manage.py seed_store      # ملء البيانات الطبية التجريبية
python manage.py runserver
```

افتح المتصفح على: `http://127.0.0.1:8000/`
ولمعاينة لوحة الإدارة: `http://127.0.0.1:8000/admin/`

## 🔒 الأمان وحماية البيانات
- يتم تحميل مفاتيح Cloudinary و Django Secret Key عبر متغيرات البيئة فقط (`python-dotenv`).
- ملف `.env` وملفات قواعد البيانات والملفات المرفوعة محجوبة ومستثناة تماماً من Git عبر `.gitignore`.
