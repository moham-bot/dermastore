# ريمشي — المتجر الطبي التجميلي الفاخر (Remshy Dermocosmetics)

منصة تجارة إلكترونية متخصصة في مستحضرات التجميل العلاجية وطب الجلدية (Dermocosmetics)، مبنية بأحدث تقنيات **Django 5** و **Tailwind CSS** و **HTMX** و **Alpine.js** مع لوحة إدارة طبية مخصصة مدعومة بـ **Django Unfold**، وتكامل سحابي كامل مع **Cloudinary**، ونظام Design Tokens للهوية السريرية الفاخرة.

---

## ✨ المميزات والتحسينات الرئيسية (الإصدار الاحترافي)

### 1. الهوية البصرية وتصميم الواجهات (Luxury Clinical Identity)
- **أيقونة وهوية جديدة بالكامل:** استبدال رمز الشجرة/الورقة السابقة بشعار سريري فاخر يجمع بين قطرة الكريستال الجزيئية والصليب الصيدلاني الذهبي بلمسة سويسرية راقية (`logo.svg` و `favicon.svg`).
- **نظام رموز التصميم (Design Tokens):** ألوان مهدئة مدروسة (Swiss Sage `#2A5741`، Thermal Marine `#0E7490`، Warm Alabaster `#FBF9F6`، Champagne Gold `#C5A059`) مع تباين عالي وخط عربي فخم، ودعم كامل لتقليل الحركة `prefers-reduced-motion`.
- **بطاقة المنتج السريرية المتطورة (Luxury Clinical Product Card):**
  - حاوية صور موحدة الأبعاد بنسبة ثبات تمنع أي تداخل أو تشوه للصورة (`object-fit: contain`).
  - مؤشرات علمية مصغرة (الترطيب، التقشير، أمان الحساسية) مع تلميحات توضيحية (Tooltips).
  - أزرار تفاعلية فورية: إضافة سريعة للسلة، معاينة فورية (Quick View Modal) دون مغادرة الصفحة، وحفظ في قائمة الأمنيات (Wishlist).
- **مبدل عرض المنتجات (Grid / List Switcher):** إمكانية التبديل بين الشبكة والقائمة مع حفظ التفضيل محلياً في المتصفح `localStorage`.
- **شريط تنقل سفلي للهواتف الذكية (Mobile Bottom Bar):** وصول سريع بضغطة زر إلى الرئيسية، الكتالوج، السلة، المفضلة، والمستشار الصيدلاني.

### 2. الكتالوج والتسوق السريري
- كتالوج منتجات متكامل مع فلاتر تفاعلية فائقة السرعة بواسطة **HTMX** (نوع البشرة، المشكلة الجلدية، خطوات الروتين، فلاتر الأمان).
- شريط فلاتر نشطة (Active Filters Chips) لإزالة أي فلتر بنقرة زر أو مسح الكل.
- محرك أسعار متعدد العملات بالوقت الفعلي (**YER**، **SAR**، **USD**).
- حاسبة تسوق تفاعلية مع شريط هدايا تحفيزي وشحن مجاني.

### 3. أدوات صيدلانية تفاعلية متقدمة
- **خريطة الوجه التفاعلية (Interactive Face Mapper):** رسم بياني تفاعلي لتحديد مشاكل مناطق الوجه وتوصيات العلاج المخصصة.
- **المستشار الصيدلاني الذكي (5-Step Diagnostic Quiz):** تشخيص نوع البشرة ومشاكلها وبناء وصفة طبية قابلة للطباعة وتنزيل بطاقة روتين مخصصة.
- **مختبر التوافق الكيميائي (Compatibility Lab):** فحص فوري للتعارضات بين المواد الفعالة (مثل فيتامين C مع الريتينول أو النياسيناميد) وتنبيه المستخدم.
- **مجدول التدوير الجلدي (Skin Cycling Generator):** جدول أسبوعي ذكي لروتين الـ 4 ليالٍ (تقشير، ريتينول، تعافي، تعافي).
- **مفكك المكونات (INCI Decoder):** تحليل المكونات الكيميائية وتصنيفها وظيفياً وأمانها على البشرة.
- **جدول المقارنة السريري (Side-by-side Comparator):** مقارنة تفصيلية جنباً إلى جنب حتى 3 منتجات.

### 4. تكامل Cloudinary وأمر ملء المنتجات الواقعية
- رفع صور المنتجات إلى مجلد مخصص في Cloudinary: `medical_store/products/`.
- تحسين تلقائي للصور باستخدام `f_auto` و `q_auto` للحصول على أعلى نقاوة وأخف حجم ممكن.
- أمر إدارة مخصص لتوليد المنتجات التجريبية الواقعية مباشرة من مجلد الصور المحلي `image/`:
  ```bash
  python manage.py seed_demo_store
  ```
- قراءة وتوثيق دقيق لبيانات ومطابقة الصور من خلال ملف `image_manifest.csv`، مع ربط كل منتج بـ `sku` فريد واسم الملف الأصلي `original_filename` لمنع أي تكرار.
- إنشاء مستخدم لوحة الإدارة التجريبي:
  - **اسم المستخدم:** `mohammed`
  - **كلمة المرور الافتراضية:** `12345` (أو المحددة في متغير البيئة `ADMIN_DEFAULT_PASSWORD`).
  - *تنبيه أمني:* يجب تغيير كلمة المرور فوراً في بيئة الإنتاج أو استخدام كلمة مرور قوية عبر متغيرات البيئة.

### 5. الطلب وفاتورة الواتساب الذكية

## 🛠️ التثبيت والتشغيل المحلي

### 1. استنساخ المشروع وتثبيت الاعتماديات:
```bash
git clone https://github.com/moham-bot/dermastore.git
cd dermastore
python -m venv venv
# تفعيل البيئة الافتراضية
# على ويندوز:
venv\Scripts\activate
# على لينكس/ماك:
source venv/bin/activate

pip install -r requirements.txt
```

### 2. إعداد المتغيرات البيئية:
انسخ ملف `.env.example` إلى `.env` واملأ بياناتك:
```bash
cp .env.example .env
```
محتوى `.env`:
```env
DEBUG=True
SECRET_KEY=your-django-secret-key
ALLOWED_HOSTS=localhost,127.0.0.1

# Cloudinary
CLOUDINARY_CLOUD_NAME=aeildie1
CLOUDINARY_API_KEY=your_cloudinary_api_key
CLOUDINARY_API_SECRET=your_cloudinary_api_secret

# Admin Superuser
ADMIN_USERNAME=mohammed
ADMIN_DEFAULT_PASSWORD=12345

# WhatsApp Business
WHATSAPP_NUMBER=967778550938
```

### 3. تجهيز قاعدة البيانات وتشغيل السيرفر:
```bash
python manage.py migrate
python manage.py seed_demo_store   # رفع الصور إلى Cloudinary وملء الكتالوج وتجهيز الأدمن
python manage.py runserver
```

افتح المتصفح على: `http://127.0.0.1:8000/`  
ولمعاينة لوحة الإدارة الفاخرة: `http://127.0.0.1:8000/admin/`
